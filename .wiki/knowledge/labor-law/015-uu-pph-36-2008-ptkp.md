# UU PPh 36 Tahun 2008 Penghasilan Tidak Kena Pajak PTKP

## Why This Matters for cekwajar.id
PPh 21 calculation adalah inti dari payroll. PTKP adalah threshold di mana pajak mulai dikenakan. Salah klasifikasi PTKP (terutama untuk status) leads to incorrect tax withholding dan potential underpayment penalties.

## Core Knowledge

### PTKP Terbaru (Sesuai PMK)

**PTKP per Tahun**:

| Status | PTKP per Tahun |
|--------|----------------|
| Tidak Kawin (TK/0) | Rp 54.000.000 |
| Tidak Kawin dengan 1 tanggungan (TK/1) | Rp 58.500.000 |
| Tidak Kawin dengan 2 tanggungan (TK/2) | Rp 63.000.000 |
| Tidak Kawin dengan 3 tanggungan (TK/3) | Rp 67.500.000 |
| Kawin (K/0) | Rp 58.500.000 |
| Kawin dengan 1 tanggungan (K/1) | Rp 63.000.000 |
| Kawin dengan 2 tanggungan (K/2) | Rp 67.500.000 |
| Kawin dengan 3 tanggungan (K/3) | Rp 72.000.000 |

**Tanggungan** = Anak kandung, anak angkat yang menjadi tanggungan sepenuhnya, paling banyak 3 orang.

### Tarif PPh Pasal 21 (Pasal 23)

**Wajib Pajak Orang Pribadi Dalam Negeri**:

| Lapisan PKP (Setahun) | Tarif |
|----------------------|-------|
| ≤ Rp 60.000.000 | 5% |
| > Rp 60.000.000 - ≤ Rp 250.000.000 | 15% |
| > Rp 250.000.000 - ≤ Rp 500.000.000 | 25% |
| > Rp 500.000.000 - ≤ Rp 5.000.000.000 | 30% |
| > Rp 5.000.000.000 | 35% |

```typescript
interface PTKPData {
 status: 'TK' | 'K';
 jumlahTanggungan: 0 | 1 | 2 | 3;
}

function getPTKP(ptkp: PTKPData): number {
 const basePTKP = {
 'TK': 54000000,
 'K': 58500000
 };
 
 const tambahan = ptkp.jumlahTanggungan * 4500000;
 
 return basePTKP[ptkp.status] + tambahan;
}

function hitungPKP(gajiBrutoSetahun: number, ptkp: PTKPData): number {
 const ptkpValue = getPTKP(ptkp);
 return Math.max(0, gajiBrutoSetahun - ptkpValue);
}

function hitungPPh21(
 gajiPokokSetahun: number,
 tunjanganTetapSetahun: number,
 tunjanganTidakTetapSetahun: number,
 biayaJabatanSetahun: number,
 iuranPensiunSetahun: number,
 ptkp: PTKPData
): {
 pkp: number;
 pph21Setahun: number;
 pph21Sebulan: number;
} {
 // Total penghasilan gross per tahun
 const totalPenghasilan = 
 gajiPokokSetahun + 
 tunjanganTetapSetahun + 
 tunjanganTidakTetapSetahun;
 
 // Pengurangan
 const totalPengurangan = biayaJabatanSetahun + iuranPensiunSetahun;
 
 // Neto
 const penghasilanNeto = totalPenghasilan - totalPengurangan;
 
 // PKP
 const pkp = hitungPKP(penghasilanNeto, ptkp);
 
 // PPh 21 setahun dengan tarif progresif
 const pph21Setahun = hitungTarifProgresif(pkp);
 
 return {
 pkp,
 pph21Setahun: Math.round(pph21Setahun),
 pph21Sebulan: Math.round(pph21Setahun / 12)
 };
}
```

```typescript
function hitungTarifProgresif(pkp: number): number {
 let pph = 0;
 
 if (pkp <= 60000000) {
 pph = pkp * 0.05;
 } else if (pkp <= 250000000) {
 pph = 60000000 * 0.05 + (pkp - 60000000) * 0.15;
 } else if (pkp <= 500000000) {
 pph = 60000000 * 0.05 + 
 190000000 * 0.15 + 
 (pkp - 250000000) * 0.25;
 } else if (pkp <= 5000000000) {
 pph = 60000000 * 0.05 + 
 190000000 * 0.15 + 
 250000000 * 0.25 + 
 (pkp - 500000000) * 0.30;
 } else {
 pph = 60000000 * 0.05 + 
 190000000 * 0.15 + 
 250000000 * 0.25 + 
 4500000000 * 0.30 + 
 (pkp - 5000000000) * 0.35;
 }
 
 return pph;
}

interface PPh21Input {
 gajiPokok: number;
 tunjanganTetap: number;
 tunjanganTidakTetap: number;
 biayaJabatan: number; // 5% dari penghasilan, maks 500.000/bulan atau 6.000.000/tahun
 iuranPensiun: number; // 1% dari gaji (jika ada)
 ptKP: PTKPData;
 isBulanTerakhir: boolean;
 isResignMidYear: boolean;
}

function calculatePPh21Bulanan(input: PPh21Input): number {
 const {
 gajiPokok,
 tunjanganTetap,
 tunjanganTidakTetap,
 biayaJabatan,
 iuranPensiun,
 ptKP,
 isBulanTerakhir,
 isResignMidYear
 } = input;
 
 // Hitung neto bulanan
 const totalPenghasilan = gajiPokok + tunjanganTetap + tunjanganTidakTetap;
 const totalPengurangan = biayaJabatan + iuranPensiun;
 const netoBulanan = totalPenghasilan - totalPengurangan;
 
 //annualize untuk kalkulasi
 const ptkpTahunan = getPTKP(ptKP);
 const netoTahunan = netoBulanan * 12;
 const pkpTahunan = Math.max(0, netoTahunan - ptkpTahunan);
 
 // Hitung PPh tahunan
 let pphTahunan = hitungTarifProgresif(pkpTahunan);
 
 // Kurangi jika bukan bulan terakhir dan bukan resign mid-year
 if (!isBulanTerakhir && !isResignMidYear) {
 pphTahunan = pphTahunan - (ptkpTahunan > netoTahunan ? 0 : pphTahunan);
 }
 
 return Math.round(pphTahunan / 12);
}

// Biaya jabatan calculation
function hitungBiayaJabatan(gajiPokok: number, tunjanganTetap: number): number {
 const penghasilan = gajiPokok + tunjanganTetap;
 const biayaJabatan = Math.min(penghasilan * 0.05, 500000);
 return Math.round(biayaJabatan);
}
```

### PTKP dan PTKP Istri

Jikasuami/istri juga bekerja dan masuk kategori "K", PTKP tidak digabung. Masing-masing WP pribadi memiliki PTKP sendiri-sendiri.

## Edge Cases and Common Mistakes

1. **PTKP salah status**: Remarried but belum update status = salah calculation
2. **PTKP double dengan istri**: PTKP WP pribadi tidak digabung dengan WP Lain
3. **Biaya jabatan berlebihan**: Maks 6jt/tahun atau 500rb/bulan
4. **Mid-year resignation**: Perlu annualisasi dan adjustment
