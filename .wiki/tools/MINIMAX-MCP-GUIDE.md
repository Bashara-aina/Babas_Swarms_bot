# MiniMax MCP — Legion Usage Guide
Updated: auto-generated by OpenCode setup

## Available MCP Tools

### MiniMax-CodingPlan (web_search + image_understanding)
Activated automatically when OpenCode needs web search or image input.

**web_search** — triggered when:
- User asks about current events, prices, news
- User asks "search for...", "look up...", "find..."
- Legion needs to research before answering
- Any factual question about post-2024 events

Usage in prompts:
```
Use web_search to find the latest [topic]
```

**understand_image** — triggered when:
- User sends an image and asks a question
- Bashara pastes a screenshot for debugging
- Any visual analysis task

### MiniMax-Full (image generation + speech + video)

**Image generation** — triggered by:
- "generate an image of..."
- "create a diagram for..."
- "visualize..."

**Text to speech** — triggered by:
- "read this out loud"
- "convert to speech"
- "generate audio for..."
- Voices: 300+ available, supports Indonesian + Japanese + English

## Rate Limits (Plus Plan)
- 4,500 requests per 5 hours
- ~50 TPS normal, 100 TPS off-peak
- Reset: rolling 5-hour window

## If Tools Don't Auto-Trigger
Explicitly tell OpenCode:
"Use MiniMax web_search MCP for this"
"Use MiniMax understand_image for this file"
"Use MiniMax image generation to create this"

## MINIMAX_GROUP_ID
Required for Full MCP (image gen + speech).
Find at: https://platform.minimax.io → Dashboard → API Keys → Group ID
Add to: ~/swarm-bot/.env as MINIMAX_GROUP_ID=your_id_here
