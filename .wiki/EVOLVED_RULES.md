# EVOLVED RULES — M2.7 Self-Evolution System

> These rules emerged from MiniMax M2.7's own self-optimization process.
> Generated by `evolve()` after each agent run. Do not edit manually.

## Self-Evolution Loop

The self-evolution loop records sessions, identifies patterns, and evolves rules:

1. **Record**: `record_session()` captures task, approach, outcome
2. **Evolve**: `evolve(last_n=5)` analyzes recent sessions for improvements
3. **Sync**: Evolved rules sync to `lib/legiona/memory/rules.md`
4. **Load**: Next session loads evolved rules via `load_evolved_rules()`

## Current Evolved Rules

### Anti-Hallucination Rules
- All factual claims must be grounded in retrieved context or tagged `[UNVERIFIED]`
- Volatile info (versions, API endpoints, prices) must be tagged `[VERIFY BEFORE USE]`
- Never present P5/P6 evidence as P1-P3 confidence

### Loop Prevention Rules
- Read same file >2x → STOP and summarize
- Run same command >2x → STOP and change approach
- 3 identical tool results → STOP and escalate
- 8+ tool calls without progress → STOP and replan

### Reasoning Rules
- Interleave CoT after every tool call (M2.7 performance optimization)
- Temperature 1.0 + reasoning_split=True for M2.7 coding tasks
- 85% confidence gate before irreversible actions
- Max 5 autonomous steps before human checkpoint

### Context Management Rules
- 196,608 token context — prefer full file contents over summaries
- Re-read original instruction before output to prevent drift
- When context saturates, request goal reconfirmation

### Coding Discipline
- Use only confirmed libraries from `package.json`, `requirements.txt`, `pyproject.toml`
- Call only APIs/functions visible in the codebase
- Never invent file paths or guess env vars

## Sync Schedule
- **Primary**: After each agent run via `evolve()`
- **Backup**: Weekly via `lint_wiki()`
- **Persistence**: `lib/legiona/memory/global_memory.md` (cross-session)
