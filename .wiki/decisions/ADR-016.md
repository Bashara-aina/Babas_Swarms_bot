# ADR-016: Consolidate 4 Orchestrators into 1

**Date:** 2026-04-12  
**Status:** Accepted  
**Priority:** 7 (Legion Depth Upgrade)

## Context

Four orchestrator files existed with unclear ownership and overlapping concerns:

| File | Lines | Unique Value |
|------|-------|---------------|
| `task_orchestrator.py` | 492 | Task chaining, confirmation queue, monitor loops, `SwarmDebateOrchestrator` (4-round debate) |
| `core/legion_swarm.py` | 322 | 3-phase parallel swarm with 11 hardcoded LEGION_TEAM agents, debate rounds, synthesis |
| `core/nexus_orchestrator.py` | 385 | 3-layer semantic routing (keyword → embeddings → LLM), department routing |
| `core/jarvis_orchestrator.py` | 207 | Context bundle: memory + Screenpipe + WhatsApp + calendar + emotion |

All four are imported and used in different parts of the codebase with no clear single owner.

## Decision

Consolidate into a single `core/orchestrator.py` that merges the unique value of each:

1. **Task chaining, confirmation queue, monitors** — keep from `task_orchestrator.py`
2. **SwarmDebateOrchestrator** — keep (used by `/swarm` command)
3. **LegionSwarmOrchestrator** — replace hardcoded 11-agent team with dynamic team selection from `AgentRegistry.select_team()`
4. **Nexus routing** — merge 3-layer routing (keyword/semantic/LLM) as the default routing path
5. **Jarvis context bundle** — expose `gather_jarvis_bundle()` for context enrichment before LLM calls

New canonical entry point: `core/orchestrator.py` → `LegionOrchestrator`

## Consequences

- **Before:** 4 files, unclear which to call
- **After:** 1 file, `LegionOrchestrator.run(task, user_id)` is the single public API
- Old files archived to `_archive/` with stubs that import from `core/orchestrator.py`
- `AgentRegistry.select_team()` added to enable dynamic team selection
- `verify_wiring.py` updated to test `core.orchestrator`

## Migration Path

1. Create `core/orchestrator.py` (new canonical orchestrator)
2. Add `AgentRegistry.select_team()` method
3. Create stubs in old locations importing from `core/orchestrator.py`
4. Archive originals to `_archive/`
5. Update `verify_wiring.py` to include `core.orchestrator`

## Alternatives Considered

- **Keep all 4** — rejected: unclear ownership, duplicate routing logic, 4 different APIs
- **Delete old files without stubs** — rejected: would break existing call-sites
- **Stub + archive** — accepted: preserves git history, clear migration path
