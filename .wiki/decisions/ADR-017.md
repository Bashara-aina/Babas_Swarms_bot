# ADR-017: Fix Fake Skills (Timer + Code Review)

**Date:** 2026-04-12
**Status:** Accepted
**Priority:** 8 (Legion Depth Upgrade)

## Context

During the Legion depth upgrade audit, two skills were identified as non-functional:
- **Timer** (scored 1/10) - was a stub that returned a confirmation string without scheduling anything
- **Code Review** (scored 0/10) - was not registered as a skill at all (existed in `tools/` but not in `core/skills/`)

## Decision

### 1. Create `core/skills/timer.py` — Real Async Timer

**Problem:** The old `_timer_handler` in `productivity.py` was a stub:
```python
# OLD - just returned text, never scheduled anything
async def _timer_handler(text: str) -> str:
    return f"⏱️ Timer set: {label}\n...I'll notify you when it expires."
```

**Solution:** Created `core/skills/timer.py` with a working implementation:
- Uses `asyncio.create_task()` to schedule background reminders
- Stores bot reference via `set_bot()` called from `main.py` on_startup
- Parses natural language timer requests (e.g., "set timer 5 min for meeting")
- Sends Telegram message when timer expires

Key implementation:
```python
async def execute(user_id: int, duration_seconds: int, reminder_text: str) -> str:
    async def send_reminder():
        await asyncio.sleep(duration_seconds)
        await bot.send_message(chat_id=user_id, text=f"⏰ Timer! {reminder_text}")
    asyncio.create_task(send_reminder())
    return f"✅ Timer set for {minutes} minute(s). I'll ping you."
```

### 2. Create `core/skills/code_review.py` — Working Code Review

**Problem:** Code review existed in `tools/code_reviewer.py` but wasn't registered as a skill in `SkillRegistry`.

**Solution:** Created `core/skills/code_review.py` that:
- Registers as a skill with keywords: "review code", "cek bug", "review kode", etc.
- Uses `llm_client.call_llm()` with coding model
- Returns structured review with BUGS/PERFORMANCE/SECURITY/IMPROVEMENTS/VERDICT sections
- Auto-detects programming language

### 3. Wire Timer Bot Reference

Added to `main.py` on_startup:
```python
from core.skills.timer import set_bot as timer_set_bot
timer_set_bot(bot)
```

## Consequences

- Timer skill now actually works — background task sends Telegram message after duration
- Code review is now a registered skill discoverable via `find_by_example()`
- Skill registry count increased from ~26 to 28 skills
- All 383 tests continue to pass
- verify_wiring.py passes all checks
