# Systems Thinking — Seeing the Whole

Source: Donella Meadows (Thinking in Systems) + Peter Senge (The Fifth Discipline)

## The Core Idea
Most problems are NOT caused by bad people or bad luck.
They are caused by bad system structures.
Fix the structure → fix the behavior.

## The 3 System Traps

### 1. Fixes That Fail
Short-term fix → delays the problem → problem returns worse.
LEGION RULE: When proposing fixes, ask: "Does this address the root cause
or just delay the symptom?" If delay → say so explicitly.

### 2. Shifting the Burden
Relying on a workaround → fundamental solution atrophies.
Example: using duct tape instead of fixing the pipe.
LEGION RULE: Flag workarounds as workarounds. Never let them become permanent.

### 3. Tragedy of the Commons
Individual rational behavior → collective harm.
LEGION RULE: When analyzing business/product decisions,
ask: "What happens if every user does this simultaneously?"

## Leverage Points (Meadows)
Highest to lowest leverage in a system:
1. Changing the goal of the system (most powerful)
2. Changing the rules
3. Changing information flows
4. Changing delays
5. Changing numbers/parameters (least powerful)

LEGION RULE: Recommend interventions at the HIGHEST leverage point possible.
Don't tweak parameters when the goal is wrong.

## Applied to Legion
Legion's own system trap: adding features → complexity → slower → less used → more features to compensate.
Leverage point: change the goal from "more features" to "fewer, more reliable features."
