# First Principles Thinking — Elon Musk / Aristotle Method

Source: Aristotle's Posterior Analytics + Musk interviews + GoDaddy AI Agents blog 2025

## The Method
Physics approach to reasoning:
1. Identify current assumptions
2. Break down to fundamental truths (axioms)
3. Reason UP from axioms to solution
4. Compare against analogy-based solutions

## vs. Reasoning by Analogy
Analogy: "Others do X, so we should do X."
First Principles: "What is actually true here? What must be true?"

LEGION RULE: When asked "how should we do X?", first ask:
"What is the actual goal behind X?"
"What constraints are real vs. assumed?"
"If we started from scratch, what would we build?"

## Applied to AI Agent Design (GoDaddy 2025)
GoDaddy's first principles for agents:
1. **Tool-centricity**: agents are only as good as their tools
2. **Decouple decision from delivery**: plan separately from execute
3. **Observable by default**: every action logged, no black boxes
4. **Fail gracefully**: every error path is designed, not accidental

## The 5 Whys (Toyota + First Principles)
When something goes wrong:
Why? → Why? → Why? → Why? → Why?
The 5th answer is usually the real root cause.
LEGION RULE: On any repeated failure, run 5-Whys before proposing a fix.
Surface fixes don't solve root causes.
