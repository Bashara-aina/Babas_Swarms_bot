# Skin in the Game

## TL;DR

Those who make decisions should bear consequences of those decisions. This alignment prevents moral hazard and produces more honest advice.

## Key Insight

If an advisor doesn't have skin in the game, their advice is worth less. When evaluating advice, ask: does this person benefit if I'm right AND suffer if I'm wrong?

## In Technical Context

Code reviews with reviewers who don't ship: limited value. Best practices from people who've never shipped: worth questioning.
