Section 1

Original FiLM (Pérez et al., AAAI 2018)

FiLM was designed for Visual Question Answering on CLEVR — learning to answer questions like "Is there a red cube to the left of the blue sphere?" by conditioning visual feature maps on a language encoding.

The Core Equation

FiLM Modulation
FiLM(Fi,c | γi,c, βi,c) = γi,c · Fi,c + βi,c

Where Fi,c is the c-th feature map channel of the i-th intermediate layer, γ scales it, and β shifts it.

Key Properties

  • 🔓 Unbounded γ and β — no activation function applied
  • 📝 Conditioning source: GRU-encoded natural language question
  • 🔁 Applied at: every residual block in the visual network
  • 🎯 Task: Visual QA (CLEVR dataset)
  • 📉 Result: Halved state-of-the-art error on CLEVR
  • 🔀 Polarity flip possible: γ < 0 inverts feature activations

Pipeline Architecture

Input Question Text
↓ GRU encoder
γ, β predictors per block Separate MLPs
↓ modulate at every ResBlock
VQA Answer Output
Section 2

What POPW Changes

POPW applies FiLM in a fundamentally different context — assembly action recognition from video, where the conditioning signal is not language but predicted human pose.

Dimension Original FiLM (2018) POPW
Conditioning input Natural language question → GRU vector 17 keypoints + confidence → 51D pose vector in-network predicted
Conditioning source External encoder (separate branch) Same backbone — pose head feeds back into FiLM closed loop
γ bounds Unbounded ∈ ℝ polarity flip possible 1 + tanh(z) → γ ∈ (0, 2) no polarity flip
β bounds Unbounded ∈ ℝ tanh(z) → β ∈ (−1, +1) bounded
Application point Every residual block Single C5 before GAP — tensor shape [B, 2048, 7, 7]
Multi-task No (single-task VQA) Yes — detection + pose + activity + Kendall uncertainty
Gradient loop Open (NLP branch decoupled) Closed — activity loss flows back through FiLM into pose head novel
FiLM MLP size ~per-layer weight vectors 51 → 128 → 256 → 4096 params (~4.4% of ResNet-50)

Original: Open Gradient Loop

Language encoder loss → updates GRU only
Visual backbone loss → updates ResNet only
No cross-path gradient flow between conditioning and visual features

POPW: Closed Gradient Loop

Activity loss → backprop through FiLM → pose head
Pose head learns what activations help activity classification
Bi-directional optimization between tasks

Original
γ = z  (identity, unbounded)
POPW
γ = 1 + tanh(z) ∈ (0, 2)

β = tanh(z) ∈ (−1, +1)

Bounded shift prevents catastrophic offset that would overwhelm the scaled activation.

Section 4

Three Research Hypotheses

POPW is built on three hypotheses, each testable through the ablation study.

H1 · Core Hypothesis

Pose conditioning improves activity recognition

Predicted human pose, used as a FiLM conditioning signal, provides structural priors about body configuration that reduce visual ambiguity in assembly action classification.

Evidence: +11.6pp Top-1 (improved3film vs improved3, 1% GT data)
H2 · Mechanistic Hypothesis

Benefit migrates as pose quality saturates

FiLM's activity gain is inversely proportional to pose quality. As PCKh saturates toward 100%, the benefit shifts from activity classification toward bounding box detection precision.

Evidence: At PCKh 99.5% — activity gain ~0pp, but mAP@0.5 gains +6.5pp
H3 · Design Hypothesis

FiLM beats cross-attention for 51D structured pose

For a low-dimensional, structurally-interpretable pose vector (51D), FiLM-style feature modulation achieves better accuracy than cross-attention at a fraction of the parameter cost.

Reference: FlexLoc (2024) — FiLM-style CLN: 4× lower error vs cross-attn for pose conditioning
Section 5

Architectural-Level Novelties

The strongest novelties in POPW are not training tricks — they are structural decisions built into the computation graph. This section summarizes the claims; the interactive lab (Section 3) animates C5 pre-GAP FiLM, the closed loop, the detach gate, and P4+FiLM-C5 fusion.

Novelty hierarchy

#1 strongest
FiLM applied to C5 before GAP
FiLM modulates the [B, 2048, 7×7] spatial map before global average pooling. The modulation affects 49 spatial positions per channel, so aggregation itself becomes pose-conditioned.
#2 coupled
Closed-loop gradient architecture
Activity loss flows through FiLM into the pose pathway, so pose representations are optimized not only for localization but also for conditioning usefulness.
#3 gate
Detached confidence head
The confidence branch uses .detach() on its input features, creating a one-way gate that blocks confidence gradients from shaping the backbone.
honorable mention
Dual-stream activity fusion
The activity head fuses GAP(FiLM(C5)) with GAP(P4), mixing a pose-conditioned deep stream with an unconditioned object-context stream.

1) FiLM at C5 before GAP

Input: ResNet C5 feature map [B, 2048, 7×7]
Operation: channel-wise FiLM modulation across all 49 spatial positions
Effect: pose determines which semantic channels are amplified before spatial collapse
Why novel: conditioning changes the aggregation process itself, not only the flattened embedding

2) Closed-loop gradients

Pose Head → 51D vector → FiLM MLP → γ,β
↓
FiLM(C5) → Activity Head → Activity Loss
↓
Backprop through FiLM → Pose representation updates
Interpretation
One task's output becomes another task's conditioning input, so the graph itself couples representation learning and recognition.

3) Detached confidence gate

Forward graph: backbone features → confidence head uses .detach()
Allowed gradients: pose coordinate branch updates backbone
Blocked gradients: confidence prediction does not reshape backbone features
Why novel: one-way information gate stabilizes training by isolating noisy confidence supervision

4) Dual-stream activity fusion

Stream A: GAP(FiLM(C5)) — pose-conditioned deep semantics
Stream B: GAP(P4) — mid-level object-scale context
Fusion: concatenation before activity classifier
Why novel: conditioned and unconditioned streams are intentionally mixed instead of forcing both through FiLM
