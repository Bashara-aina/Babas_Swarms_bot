# Summary

This paper presents a prompt-enhanced hierarchical transformer approach for temporal action segmentation. The method uses prompt tokens to guide the transformer toward more accurate boundary detection and class prediction in long-form video.

## Key Contributions

1. **Hierarchical Transformer**: Multi-scale temporal modeling for action segmentation
2. **Prompt Enhancement**: Uses prompts to guide boundary detection
3. **Temporal Modeling**: Captures long-range dependencies in video sequences
