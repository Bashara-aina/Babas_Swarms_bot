## Abstract

*Note: Abstract based on paper understanding from ICLR publication.*

Multi-task learning often suffers from imbalanced task contributions where some tasks dominate the optimization. This paper proposes Impartial Multi-Task Learning (IMTL) to address the fundamental issue of task imbalance in MTL. The key insight is that an impartial MTL algorithm should not require explicit task weighting — instead, it should automatically achieve balance through its optimization dynamics.

---

## Key Contributions

1. **Impartiality principle**: No task should be systematically favored or disadvantaged
2. **Gradient magnitude balancing**: Ensures tasks contribute equally to parameter updates
3. **No manual hyperparameters**: Self-correcting optimization dynamics
4. **Theoretical analysis**: Proves convergence and balance properties

---

## Method Details

### Impartiality Definition
An impartial optimizer treats all tasks equally by:
- Monitoring gradient magnitudes across tasks
- Adjusting updates to balance contributions
- Not relying on loss values as proxies for importance

### Core Algorithm (inferred)
1. Compute per-task gradients: $g_i = \nabla_\theta L_i$
2. Compute gradient magnitudes: $m_i = \|g_i\|$
3. Normalize to get balanced weights: $\tilde{w}_i = m_i^{-1} / \sum_j m_j^{-1}$
4. Update with weighted gradient: $\Delta\theta = \sum_i \tilde{w}_i g_i$

### Key Properties
- **Automatic**: No hand-tuned hyperparameters
- **Balanced**: Ensures equal gradient contribution
- **Principled**: Based on impartiality rather than heuristics

## Limitations

1. May be overly conservative if task importances differ
2. Equal gradient contribution ≠ equal task importance
3. Performance may lag behind methods with tuned hyperparameters
