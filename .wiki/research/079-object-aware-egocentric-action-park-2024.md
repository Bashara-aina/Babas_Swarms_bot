# Summary

This paper presents an object-aware approach to online egocentric action detection. The method processes egocentric video streams in real-time, using object context to improve action recognition accuracy. Particularly relevant for assembly scenarios where hand-object interactions are key.

## Key Contributions

1. **Online Detection**: Real-time processing of egocentric video streams
2. **Object Integration**: Uses detected objects as context for action recognition
3. **Egocentric Focus**: Designed specifically for first-person camera viewpoints
