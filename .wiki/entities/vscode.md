# Visual Studio Code

## Overview

Visual Studio Code (VS Code) is a source code editor developed by Microsoft for Windows, Linux, and macOS. It includes support for debugging, embedded Git control, syntax highlighting, intelligent code completion, snippets, and code refactoring.

## Key Features

- **Extensible**: Large ecosystem of extensions for various languages and tools
- **Integrated Terminal**: Built-in terminal for command-line tasks
- **Git Integration**: Source control via Git lens and built-in Git tools
- **Debugging**: Built-in debugging support for Node.js, Python, and more

## Notes

Cursor is built on the VS Code codebase. Swarm-bot can operate in both VS Code and Cursor environments via the vscode-bridge component.
