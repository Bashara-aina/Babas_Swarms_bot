# Ego-Exo4D — Egocentric/Exocentric Video Benchmark

## Overview

Ego-Exo4D is a large-scale video dataset created for benchmarking action recognition models. The dataset captures both first-person (egocentric) and third-person (exocentric) views of activities, enabling research into how visual understanding differs between these perspectives.

## Key Features

- **Multi-view Dataset**: Both first-person and third-person camera angles
- **Action Labels**: Comprehensive action taxonomy for benchmarking
- **Research Benchmark**: Used for comparing pose-derived detection approaches
