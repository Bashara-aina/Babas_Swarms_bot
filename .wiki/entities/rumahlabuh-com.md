# RumahLabuh — Property Rental Platform

## Overview

rumahlabuh.com is a platform for renting boarding houses (kos) and rooms in Indonesia. It helps landlords list properties and potential tenants find rooms.

## Tech Stack

- **Frontend**: Next.js
- **Database**: Supabase (PostgreSQL + pgvector)
- **Hosting**: Cloudflare
