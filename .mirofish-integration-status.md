## Architecture
```
Telegram → Legion handlers → tools/market_intel.py
                                       ├── yfinance (real OHLCV prices)
                                       ├── duckduckgo_search (news, Bahasa+EN)
                                       ├── _score_sentiment() (keyword scorer)
                                       ├── _generate_signals() (BUY/ACCUMULATE/HOLD/WATCH/AVOID)
                                       └── MiroFish API (localhost:5001)
                                             ├── ReportAgent (LangGraph report generation)
                                             ├── SimulationRunner (OASIS multi-agent simulation)
                                             ├── Zep knowledge graph
                                             └── LLM: MiniMax-M2.7 via https://api.minimax.io/v1
```

```env
ZEP_API_KEY=<optional_for_zep_graph>
```

## Known limitations
- Sentiment scorer is keyword-based (fast pre-filter). MiroFish LLM analysis is deeper but requires LLM calls.
- DDGS (duckduckgo_search) rate-limits news API — news fetch may return 0 articles under heavy use. Fallback to Tavily or Exa for production news.
- IDX market hours: 09:00–15:30 WIB (Mon–Fri). Heavy simulations scheduled for off-hours only.
- yfinance rate limit: ~2000 req/day free. Results are fresh per call (no caching layer yet).
