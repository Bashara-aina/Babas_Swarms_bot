# /threads-mode

Toggle dedicated Threads campaign mode from Claude Code.

## Usage

```bash
python .claude/commands/threads-mode.py status
python .claude/commands/threads-mode.py on
python .claude/commands/threads-mode.py off
python .claude/commands/threads-mode.py toggle
```

When mode is turned **ON**, it also opens `https://www.threads.com/@rumahlabuh` on desktop browser.
