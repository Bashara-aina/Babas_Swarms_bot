# Communication Modes Reference

Quick reference for switching between communication modes.

## Caveman Mode

**Activates:** "caveman mode", "talk like caveman", "less tokens", "be brief"

**Deactivates:** "stop caveman", "normal mode"

## Normal Mode

Standard professional communication with full sentences, articles, and explanations.

## When to Use Each

| Situation | Mode |
|-----------|------|
| Debugging, quick questions | Caveman |
| Complex explanations | Normal |
| Security warnings | Normal |
| Destructive commands | Normal |
| Writing documentation | Normal |
| Initial exploration | Normal |

## Caveman Survival Guide

### Always Keep
- Technical terms exact
- Code blocks unchanged
- Error messages quoted
- Technical accuracy

### Always Drop
- Articles (a/an/the)
- Filler words (just, really, basically, actually, simply)
- Pleasantries (sure, certainly, of course, happy to)
- Hedging (might, possibly, perhaps)

### Symbols
```
->  = causes / leads to
<-  = because of
X/Y = X or Y (choice)
X+Y = X and Y together
!   = not / negation
++  = increment / improve
--  = decrement / remove
>   = greater than / better
<   = less than / worse
```
