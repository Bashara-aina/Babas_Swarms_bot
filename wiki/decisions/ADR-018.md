# ADR-018: Add /capabilities and /self_report Commands

**Date**: 2026-04-13
**Status**: Accepted
**Priority**: P9 (Legion Depth Upgrade)

## Context

Legion could not explain its own capabilities to users. There was no `/capabilities` command to show honest status (✅ working, ⚠️ partial, ❌ not ready). There was also no `/self_report` command to show 24h activity — messages processed, recent learnings, failures.

## Decision

Add two new admin commands to `handlers/admin_handlers.py`:

### `/capabilities`
- Uses existing `core.capability_audit.CapabilityAudit.run_audit()` which checks file existence against a benchmark list
- Returns honest status with ✅ ⚠️ ❌ icons
- Shows coverage percentage

### `/self_report`
- Queries `data/message_count.py` for messages processed in last 24h
- Queries `data/self_improvement_buffer.py` for recent learnings
- Returns formatted Markdown report

## Supporting Files Created
- `data/message_count.py` — reads from `data/conversation.db`
- `data/self_improvement_buffer.py` — reads from `data/memory.db` (learning_logs or kv_store)

## Registration
- Commands registered in `main.py` `set_my_commands` list
- `admin_handlers.router` already registered in `handlers/__init__.py` `_ROUTER_ORDER`

## Consequences
- Users can now get honest capability status at any time
- Self-improvement learnings are queryable for the 24h report
- Both commands require owner authentication (same as `/budget`, `/soul`)
