# Cekwajar Phase Log

## TL;DR
cekwajar.id development spanned MVP, data collection, features, and monetization phases.

## Phase 1: MVP (2025 Q4)
- Basic salary comparison
- Manual data entry
- Single user support

## Phase 2: Data Collection (2026 Q1)
- Indonesian salary survey
- Market rate aggregation
- Data from multiple sources:
  - Glints salary insights
  - Jobstreet reports
  - BPS wage data
  - Mercer survey

## Phase 3: Feature Expansion (2026 Q2)
- PDF report generation
- Advanced filters
- Company comparisons
- Industry benchmarks

## Phase 4: Monetization (Current)
- Freemium model
- Premium features:
  - Unlimited reports
  - Historical data
  - Export features
