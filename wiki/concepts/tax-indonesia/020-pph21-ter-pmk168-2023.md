# PPh 21 Tarif Efektif Rata-Rata (TER) - PMK 168/2023

## Why This Matters for cekwajar.id
PPh 21 TER is cekwajar's **#1 most-used tax calculation**. Every payroll run requires correct TER application to compute monthly tax deductions. Wrong TER = wrong salary = employee complaints + DJP penalties. This is the foundation all other PPh 21 calculations build upon.

## Core Knowledge

Since January 2024, PPh 21 for employees uses **Tarif Efektif Rata-Rata (TER)** based on PP 58/2023 and PMK 168/2023.

**Key Principles:**
- TER simplifies monthly PPh 21 calculation by using pre-computed effective rates
- For Jan–Nov: multiply gross monthly income by applicable TER category
- In December (or final month): recalculate using progressive Pasal 17 rates, credit taxes already withheld

**Three TER Categories:**
| Kategori | PTKP Status | Annual PTKP |
|----------|-------------|-------------|
| A | TK/0 | Rp 54,000,000 |
| A | TK/1, K/0 | Rp 58,500,000 |
| B | TK/2, K/1 | Rp 63,000,000 |
| B | TK/3, K/2 | Rp 67,500,000 |
| C | K/3 | Rp 72,000,000 |

**TER Bulanan Tables (cerpted from PP 58/2023):**

*Kategori A (PTKP Rp 54M dan Rp 58,5M):*
| Gross Monthly (IDR) | TER % |
|----------------------|-------|
| 0 – 4,500,000 | 0% |
| 4,500,001 – 5,000,000 | 0.25% |
| 5,000,001 – 6,000,000 | 0.5% |
| 6,000,001 – 7,000,000 | 0.75% |
| 7,000,001 – 8,000,000 | 1.0% |
| 8,000,001 – 9,000,000 | 1.5% |
| 9,000,001 – 10,000,000 | 2.0% |
| 10,000,001 – 12,000,000 | 2.5% |
| 12,000,001 – 15,000,000 | 3.0% |
| 15,000,001 – 18,000,000 | 3.5% |
| 18,000,001 – 22,000,000 | 4.0% |
| 22,000,001 – 25,000,000 | 4.5% |
| 25,000,001 – 30,000,000 | 5.0% |
| 30,000,001 – 35,000,000 | 6.0% |
| 35,000,001 – 40,000,000 | 7.0% |
| 40,000,001 – 45,000,000 | 8.0% |
| 45,000,001 – 50,000,000 | 9.0% |
| > 50,000,000 | 10.0% |

*Kategori B and C rates differ slightly — see PP 58/2023 full tables.*

**TER Harian:**
- Gross ≤ Rp 450,000/day → 0%
- Rp 450,001 – Rp 2,500,000/day → 0.5%
- > Rp 2,500,000/day → use Pasal 17 progressive on 50% of daily gross

function getTERCategory(ptkp: number): 'A' | 'B' | 'C' {
  if (ptkp <= 58_500_000) return 'A';
  if (ptkp <= 67_500_000) return 'B';
  return 'C';
}

function lookupTER(grossMonthly: number, category: 'A' | 'B' | 'C'): number {
  const table = category === 'A' ? TER_TABLE_A : TER_TABLE_B;
  for (const tier of table) {
    if (grossMonthly >= tier.minGross && grossMonthly <= tier.maxGross) {
      return tier.terRate;
    }
  }
  return 0.10; // default max rate
}

function calculatePPh21Monthly(
  grossMonthly: number,
  ptkpAnnual: number
): number {
  const category = getTERCategory(ptkpAnnual);
  const terRate = lookupTER(grossMonthly, category);
  
  const taxMonthly = new Decimal(grossMonthly)
    .times(terRate)
    .toNumber();
  
  return Math.round(taxMonthly);
}

## Edge Cases and Common Mistakes

1. **Using wrong PTKP for categorization**: PTKP TK/1 vs K/0 both → Category A, but different PTKP values for year-end reconciliation
2. **Forgetting December reconciliation**: TER is only for Jan–Nov; December must use progressive rates minus cumulative credits
3. **Not combining all income types**: THR, bonus, overtime must be added to monthly gross before applying TER
4. **Misapplying Category B/C thresholds**: Check PTKP annually as UMK changes may shift categories
5. **Integer overflow in JavaScript**: Always use Decimal.js or integer math (store as cents/sen)
