# Superpowers SDLC Data

This directory stores artifacts generated by the Superpowers + ECC workflow integration.

## Directory Layout
- `specs/` — Design specifications from brainstorming
- `plans/` — Task breakdowns from writing-plans
- `archived/` — Completed specs and plans (moved here on branch finish)
- `homunculus/observations/` — Tool use observations for instinct learning (ECC continuous learning)
- `homunculus/instincts/` — Learned instincts (confidence-weighted behavior patterns)
- `.gateguard/` — GateGuard sentinel files (first-edit tracking)
